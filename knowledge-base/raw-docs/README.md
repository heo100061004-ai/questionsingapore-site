# Raw Docs 운영 가이드

다음 3개 폴더에 문서를 직접 넣으면 자동 인덱싱 대상에 포함됩니다.

- 고용: `knowledge-base/raw-docs/employment`
- 부동산: `knowledge-base/raw-docs/property`
- 리로케이션: `knowledge-base/raw-docs/relocation`

접근 방법

1. VS Code 탐색기에서 `knowledge-base/raw-docs`를 엽니다.
2. 원하는 카테고리 폴더를 선택합니다.
3. 문서 파일(pdf, docx, txt 등)을 드래그 앤 드롭으로 넣습니다.
4. 로컬 서버 또는 배포 환경의 자동 인덱싱이 다음 주기에서 문서를 반영합니다.

관리자 페이지 업로드와 차이

- 관리자 페이지 업로드는 선택한 카테고리 폴더로 바로 저장되도록 연결되어 있습니다.
- 직접 폴더 업로드는 운영자가 문서를 일괄 정리할 때 더 편합니다.

권장 운영 방식

- 파일명에 카테고리 또는 주제를 알 수 있는 단어를 포함합니다.
- 같은 문서를 다시 올릴 경우 최신 버전만 남기고 중복 파일은 정리합니다.
- 업로드 후 관리자 페이지의 문서 자동 업데이트 아카이브에서 반영 여부를 확인합니다.
